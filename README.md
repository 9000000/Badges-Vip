## 🛠 Tùy biến & Tái tạo (Development)

Cài đặt dependencies và tạo lại toàn bộ file GIF:
```bash
npm install
npm run generate
```

Xem trước toàn bộ bộ sưu tập tương tác:
Mở file `preview_gallery.html` trong trình duyệt bất kỳ.
